Entry for the make.fun bounty **One-Star Review of Something Essential**
(`u-0xb3e689-one-star-review-of-something-essential-c7234629`).

`main.ts` writes a single deadpan one-star review of sleep to
`entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`
(default `/output`). The review is one line, plain ASCII, no trailing
newline, no exclamation marks, and well under the 160-character limit.

> One star. Sleep takes a third of my life, demands eight hours, darkness and silence, and still returns me tired. I will be back tonight.

Run it with:

```sh
node main.ts
```
